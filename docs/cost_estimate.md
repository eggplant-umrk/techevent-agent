# 本番運用の API 代の試算（2026-11-21）

ネタ帳の更新を「新しい活動だけ・コードで落とす・上限」に直した後（feature/notebook-diff、main 2d835ed）の実測をもとに、本番で月にいくらかかるかを見積もりました。この試算のために API は使っていません（今までの記録 `data/usage.json` と、直した後の確認の結果から計算）。

## 1. 結論

| 社員数 | 今のまま（Opus 5.5・普通の API） | 下げる手をすべて入れた場合 |
| --- | --- | --- |
| 100人 | **月 約 $19〜41** | 月 約 $6〜15 |
| 300人 | **月 約 $55〜111** | 月 約 $14〜32 |

- 月 $200 の上限には、300人でも収まる。金額の9割はネタ帳の更新
- 直す前の作り（毎回全履歴を読み直す）だと、300人・週1回の更新で月 約 $350 になり、半年たつとさらに増えていた（docs/stress_report.md の3）。直した後は、活動の量に比例するだけで、履歴が長くなっても増えない
- 別に、最初の取り込み（過去の履歴を読ませる）に1回だけ 100人で $90〜180、300人で $270〜540 かかる（4）。月の上限を超えるので、数日に分けるか Message Batches で流す

## 2. 前提

| 項目 | 値 | メモ |
| --- | --- | --- |
| 社員数 | 100人／300人 | |
| PR | 1人あたり月50〜100件 | ネタ帳の更新で読む活動 |
| リリースノート | 月10〜30件 | 会社全体の件数として扱った（1人あたりだと非現実的な量のため）。ネタ帳の更新で読む活動に足す |
| 依頼 | 月10〜30件 | 受信箱に届く登壇・寄稿の依頼 |
| アンケート | 月2〜4回 | イベント後のアンケートの分析 |
| ネタ帳の更新 | 週1回、全員分 | 夜間などにまとめて流す想定 |
| モデル・料金 | ループ Opus 5.5（入力 $4・出力 $20・キャッシュ読み込み $0.2・書き込み $5／100万トークン）、重い仕事 Fable 5.2（$8・$40） | lib/pricing.ts と同じ |
| コードで落とす割合 | 0〜20% | 本人の GitHub では 1%（ボットや依存の更新がほとんどない）。会社のリポジトリは dependabot・説明のない PR が増えるので多めに見た |

## 3. 実測値（直した後）

### ネタ帳の更新（1人1回の呼び出し）

デモ用の本人（本物の GitHub、PR の本文は平均 約300字）を空の状態から流した実測：53件を渡して **$0.168**、入力 17,057・出力 3,851・キャッシュ書き込み 4,571 トークン、36.6秒。

| 内訳 | 値 | 使い方 |
| --- | --- | --- |
| 活動1件あたりの入力 | 約320トークン | 本文は400字で切るので、長い PR でも約400トークンまで |
| 活動1件あたりの出力 | 約73トークン | カードを作る・更新する分の出力を件数で割ったもの |
| **活動1件あたりの金額** | **約 $0.0027** | 320×$4 ＋ 73×$20（100万トークンあたり） |
| 1回の呼び出しの固定分 | 100人 約 $0.012／300人 約 $0.015 | 本人の情報・既存カードの要約（約1千トークン）、出力の固定分（約300トークン）、指示文のキャッシュ読み込み |
| 1回の更新ごとのキャッシュ書き込み | 100人 約 $0.05／300人 約 $0.13 | 指示文に社員一覧が入っているので、人数とともに大きくなる（30人で約4.6千トークン → 300人で約2.6万トークン） |

汚れたデータ（短い投稿）の3人でも、合計 $0.111（77件）で同じくらいの比率だった。新しい活動がない人は API を呼ばない（$0）。

### 依頼（1件あたり）

| 処理 | モデル | 実測（中央値） | 人数による変化 |
| --- | --- | --- | --- |
| Slack の依頼の読み取り | Opus 5.5 | $0.002 | なし |
| 候補を出すループ（平均4回呼び出し） | Opus 5.5 | $0.095（$0.054〜0.190、57回） | 指示文の社員一覧が増える。100人 約 $0.13、300人 約 $0.22 |
| 代わりの人を推す文（指名の依頼だけ） | Fable 5.2 | $0.031 | なし |
| 声かけの下書き | Fable 5.2 | $0.088 | なし |
| **合計** | | | **100人 約 $0.25、300人 約 $0.34** |

依頼はめったに来ないので、毎回キャッシュの書き込みからになる（ループの金額の約半分がキャッシュの書き込み）。

### アンケート（イベント1回あたり）

$0.117（$0.090〜0.195、5回）。回答の数で変わり、社員数では変わらない。

## 4. 月の金額

### ネタ帳の更新

1人の月の金額 ＝ 活動の件数 × $0.0027 ＋ 更新の回数 × 固定分

| | 100人 | 300人 |
| --- | --- | --- |
| 少ない場合（PR 50件、2割を落として40件） | 40×0.0027＋4×0.012 ＝ $0.156／人 → **$16** | 40×0.0027＋4×0.015 ＝ $0.168／人 → **$51** |
| 多い場合（PR 100件、落とさない） | 100×0.0027＋4×0.012 ＝ $0.318／人 → **$32** | 100×0.0027＋4×0.015 ＝ $0.330／人 → **$100** |

キャッシュの書き込み（月4回で $0.2／$0.5）とリリースノート（10〜30件で $0.03〜0.08）を含めても、上の数字はほぼ変わらない。

### 合計

| | 100人 | 300人 |
| --- | --- | --- |
| ネタ帳の更新（週1回） | $16〜32 | $51〜100 |
| 依頼（月10〜30件） | $2.5〜7.5 | $3.4〜10 |
| アンケート（月2〜4回） | $0.2〜0.8 | $0.2〜0.8 |
| リリースノート | $0.1未満 | $0.1未満 |
| **合計** | **約 $19〜41** | **約 $55〜111** |

### 最初の取り込み（1回だけ）

過去半年分（1人 300〜600件）を読ませると、1人 約 $0.9〜1.8。100人で $90〜180、300人で $270〜540。1回に渡す上限（60件・2万字）があるので、1人あたり5〜10回の更新に分かれる。Message Batches を使えば半額。

### 確かさ

- 活動1件あたりの金額は、本人の GitHub（1人分・1回）の実測から出した。会社の PR は本文が長いことが多いが、400字で切るので入力は最大で3割増しにとどまる
- 出力は「カードをいくつ作る・更新するか」で変わる。週1回の更新で1人1〜2枚の更新なら、上の見積もりと同じくらい
- 全体として ±3割くらいの幅があると見ておく。本番の前に、10人ほどで1か月分を流して実測で直すのがよい

## 5. さらに下げる手と効果

300人・多い場合（月 約 $111）を例にした効果。効果が大きい順。

| 手 | 内容 | 効果（300人） | 注意 |
| --- | --- | --- | --- |
| 1. Message Batches API | ネタ帳の更新を夜間にまとめて送る。料金は普通の半分 | ネタ帳 $100 → $50（**−$50**） | 結果が返るまで時間がかかる（非同期。最大で24時間）。急がない処理だけに使う。依頼（Slack で待っている）には使わない。アンケートの分析にも使えるが効果は小さい |
| 2. ネタ帳の更新を Sonnet 5.5 に | 読んでまとめる仕事なので、Opus の半額のモデル（入力 $2・出力 $10）を試す | 1と合わせて $100 → $25（**さらに −$25**） | 品質が落ちないかを、汚れたデータの確認（scripts/stress_run.ts、1回 約 $0.1）と評価で確かめてから切り替える |
| 3. 更新の回数を週1回のままにする | 毎日にすると、固定分が月20回かかる | 毎日にした場合と比べて **−$72**（100人なら −$19） | 新しい活動が「N件たまった人だけ」流す形にすると、さらに固定分が減る |
| 4. 指示文から社員一覧を外す | ネタ帳の更新は本人の情報だけで足りる。候補を出すループは、一覧の代わりに検索のツールで探す | ネタ帳 約 −$5、依頼 1件 約 −$0.12（月 −$1〜4） | 候補を出すループは、一覧があると候補の見落としが減っている可能性があるので、評価（69件）で確かめる |
| 5. 出力を減らす | 変わらないカードは出力させない、根拠の id は追加分だけ返させる | 出力はネタ帳の金額の約半分。2〜3割減らせればネタ帳の1〜1.5割（−$10〜15） | まだ測っていない |
| 6. 下書き・推す文を Opus 5.5 に | 今は Fable 5.2（Opus の倍の料金） | 1件 −$0.06、月 −$0.6〜1.8 | 声かけの文の質を確かめてから |
| 7. 軽い仕事を Haiku 5.5 に | Slack の依頼の読み取りなど、短い抜き出しは Haiku 5.5（入力 $0.10・出力 $0.50、Opus の1/40）にできる | 今の金額が小さいので月 $0.1 未満 | lib/pricing.ts に Haiku の料金がまだないので、使うなら足す。ネタ帳の更新の前に「取り組みらしいか」を Haiku でふるいにかける使い方もあるが、取りこぼしの確認が要る |

**1・2・4を入れた場合**：300人で月 約 $14〜32、100人で月 約 $6〜15（1の表。ネタ帳は今の1/4、依頼は一覧を外した分だけ下がる）。

## 6. 計算の元

- ネタ帳の更新の実測：docs/notebook_demo_result.json（本人）、docs/stress_result.json（汚れたデータ）、docs/stress_report.md の6
- 依頼・アンケートの実測：data/usage.json の記録（用途ごと・1回ごとに集計した中央値）
- 社員一覧の長さ：1人 約80トークン（候補を出すループの指示文で、30人の一覧が 2,649字）
- 料金：lib/pricing.ts（Haiku 5.5 は Anthropic の料金表の値）
