## 6. 試せていないこと

- ブラウザでの実際の連打（ボタンが押せなくなるまでの一瞬に2回押せるか）。画面のコードでは、記録・取り消し・追加・更新の各ボタンに「動いている間は押せない」が付いている
- 新しい活動があるときの「ネタ帳を更新」の2回同時（偽の API が成功を返す形を作っていない）
- API が返事をしないときに、何分で時間切れになるか（SDK の既定の値を確かめていない）
- 見せる用の本番の形（`npm run start:share`、ビルド済み）。開発サーバーに見せる用の設定を入れて試した

## 7. 試験の流し直し方

```bash
node scripts/abuse/http.mjs http://127.0.0.1:3200
```

```bash
npx tsx scripts/abuse/slack_and_data.ts
```

- 1つ目は、一時フォルダを置き場にした確認用のサーバー（3200番など。3000番・3100番には投げない作り）が要る。置き場は環境変数（`DATA_RUNTIME_DIR`・`INBOX_FILE`・`SAMPLE_PROPOSALS_FILE`・`DRAFTS_FILE`・`USAGE_FILE` など）で一時フォルダに向ける
- 途中の失敗は `scripts/abuse/fake_api.mjs`（偽の API）を立て、確認用のサーバーを `ANTHROPIC_BASE_URL=http://127.0.0.1:3299` とにせのキーで起動してから `scripts/abuse/failures.mjs`
- 2つ目は、サーバーなしで動く
