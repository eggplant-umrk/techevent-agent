# フォントのライセンス

このフォルダのフォントは、Google Fonts で配られているものを、ビルドのときに取り込んだ形のまま手元に置いたものです（unicode-range ごとに分かれた woff2）。読み込みは `app/fonts.css`。

| ファイル | フォント | 作者 | ライセンス |
| --- | --- | --- | --- |
| `inter-*.woff2` | Inter | The Inter Project Authors（https://github.com/rsms/inter） | SIL Open Font License 1.1 |
| `noto-sans-jp-*.woff2` | Noto Sans JP | Google・Adobe（Source Han Sans、https://github.com/notofonts/noto-cjk） | SIL Open Font License 1.1 |

SIL Open Font License 1.1 の本文：https://openfontlicense.org/open-font-license-official-text/

- フォントだけを単体で売ることはできません。アプリと一緒に配る・使うことはできます
- 手を加えた場合は、元の名前（Reserved Font Name）を使えません。ここでは手を加えていません
