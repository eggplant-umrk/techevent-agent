# 見せる前の確認表（メンターに触ってもらう日）

コマンドは、サーバーを動かす作業場所（main：`C:\techevent-agent`）で打つ。金額の記録（data/usage.json）は作業場所ごとにあるので、確かめるのも同じ場所で。PowerShell の行は PowerShell、それ以外は Git Bash でも PowerShell でも打てる。詳しい手順は README の「本番用のビルドで見せる」「メンターなどに別の端末から見せる」。

## 前日

| やること | コマンド | 確かめること |
| --- | --- | --- |
| 最新にする | `git pull` | `git status` が「working tree clean」で、main の最新のコミットになっている |
| 画面の操作の結果を片付ける | `npm run reset:demo` | 「移しました：… → data/runtime-backup/<日時>/…」と「初期状態に戻しました」（または「片付けるものはありませんでした」）が出る（消さずに退避。元のデータ・金額の記録は触らない） |
| テストが通る | `npm test`（API なしのテストを全部と `eval --offline`。数十秒） | 最後に「21本すべて合格」（本数はテストを足すと増える）。途中の `eval --offline` に「段階1 結合テスト：69/69」 |
| 開発サーバーを止める | 動かしているターミナルで Ctrl+C | `netstat -ano \| findstr :3000` に LISTENING が出ない（`.next` がぶつからないように） |
| 本番用のビルド | `npm run build` | 最後に「✓ Compiled successfully」と、一覧に「ƒ Proxy (Middleware)」がある（入口の確認が入っている） |
| ボットは1つだけ | PowerShell：`Get-CimInstance Win32_Process -Filter "Name='node.exe'" \| ? CommandLine -like '*slack-bot*' \| Select ProcessId, CommandLine` | 出てくるのが1行だけ（0なら `npm run slack` で起動、2以上なら古いほうを止める） |
| 使った金額 | `npm run usage` | 累計と今日の金額。月の上限（$200）と、当日の上限（SHARE_BUDGET_USD）に余裕がある |
| 本番用で一度通しで触る | `npm start` → http://127.0.0.1:3000/?mock | 受信箱・ネタ帳・アーカイブが開き、左下に開発用の「N」の丸が出ない。確かめたら Ctrl+C |

## 当日（見せる前）

| やること | コマンド | 確かめること |
| --- | --- | --- |
| 合言葉を決める | （その日だけの英数字12文字以上。パスワード管理に保存） | 前に使った合言葉と違う |
| 見せる設定を書く | `.env` に `SHARE_MODE=lan`・`ACCESS_CODE=（合言葉）`・`SHARE_BUDGET_USD=5`（必要なら `BIND_HOST=この端末のIP`） | `.env` は git に入らない（`git status` に出ない）。合言葉を画面共有やスライドに映さない |
| 起動 | `npm start` | 最初の行が「見せる設定（SHARE_MODE=lan）：http://192.168.x.x:3000 で待ち受けます…API 代の上限 $5」。「起動しません」なら合言葉が空 |
| 合言葉なしで弾かれる | 別の端末で http://192.168.x.x:3000 を開く | 合言葉の入力画面が出る（いきなり受信箱が出たら止めて設定を見直す） |
| 合言葉で入れる | その画面で合言葉を入れる | 受信箱が開く。ネタ帳・アーカイブのタブも開ける |
| 窓口は合言葉なしで使えない | `curl -s -o /dev/null -w "%{http_code}\n" http://192.168.x.x:3000/api/cards` | `401` |
| ボットが窓口に入れる | 練習用の Slack の依頼チャンネルに試しの依頼を1件投稿 | スレッドに「受け付けました。技術広報から連絡します」が付き、受信箱に入る（ボットは合言葉をヘッダーで送る） |
| ボットの接続先 | `.env` に `INBOX_BASE_URL=http://192.168.x.x:3000`（起動の最初の行に出る URL） | サーバーが LAN の IP だけで待ち受けているとき、ボットの既定の接続先（127.0.0.1）には届かない。書いたらボットを起動し直し、上の「ボットが窓口に入れる」をもう一度 |
| 合言葉を伝える（相手が決まっているとき） | URL と合言葉を別々に、口頭かメンター本人だけの DM で | 共有のチャンネル・スライド・画面共有には書かない |
| 合言葉を参加者全員に公開するとき | 合言葉は「入れる人を絞るもの」ではなくなる。`SHARE_BUDGET_USD` を必ず書く。発表で見せる画面は、公開しているサーバーとは別に立てる（この端末だけ・別のポート・`DATA_RUNTIME_DIR` で別の置き場）か、発表の前に公開を止めて `npm run reset:demo` | 起動の最初の行に「API 代の上限 $…」が出ている。合言葉を持つ人は全員、カードや人の情報の書き換え・結果の記録・会話の貼り付けができ、書いた内容は全員の画面に出る（docs/roadmap.md の「利用者と権限」） |
| 金額を始める前に控える | `npm run usage` | 今日の金額を控える（終わったあとと比べる） |

見せている間：上限（SHARE_BUDGET_USD）を超えると、候補を出す・ネタ帳の更新・分析・下書きなどは止まり、画面に理由が出る。見るだけの操作と `?mock` は続けられる。

## 終わったあと

| やること | コマンド | 確かめること |
