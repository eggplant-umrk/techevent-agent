# 見せる前の確認表（会場の参加者に触ってもらう日）

**合言葉は同じネットワークの参加者全員に公開する前提**です。合言葉を知っている人は全員使えるので、見せる用は発表用とは別のサーバー・別のデータの置き場で立て、API 代の上限を必ず付けます。

- 発表用：`npm start`（127.0.0.1:3000、この端末だけ。Slack ボットはここにつなぐ）
- 見せる用：`npm run start:share`（0.0.0.0:3100、合言葉・上限が必須。データは data/runtime-share/。発表用とほぼ同じことができる（ネタ帳を更新・この依頼の記録も）。**できないのは Slack から依頼が届くことと ?debug だけ**。API を使う操作は同時に2件まで。1人あたりの上限 SHARE_PER_PERSON_USD）

コマンドは、サーバーを動かす作業場所（main：`C:\techevent-agent`）で打つ。PowerShell の行は PowerShell、それ以外は Git Bash でも PowerShell でも打てる。詳しくは README の「会場の参加者に触ってもらう」。

見せている間：上限（SHARE_BUDGET_USD）を超えると、候補を出す・分析・下書き・ネタ帳を更新などは止まり、画面に理由が出る。側ごとの合計の上限（SHARE_GENERAL_POOL_USD・SHARE_MENTOR_POOL_USD）に届いた側は、その側だけ止まる（一般の参加者が使い切っても、メンター・審査員は続けられる）。1人あたりの上限（SHARE_PER_PERSON_USD）を超えた人は、その人だけ「この端末で試せる分を使い切りました。保存済みの例（?mock）は引き続き見られます」になる（ほかの人は続けられる）。「ネタ帳を更新」は、1回の見積もりが NOTEBOOK_BUDGET_USD を超えるなら始めず、動いている間の2回目は断る。API を使う操作が同時に2件を超えたときも、少し待つよう理由が出る。見るだけの操作と `?mock` は続けられる。
