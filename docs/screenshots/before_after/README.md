# 画面の引き算（before → after）

`?mock` で撮影。番号が同じものが同じ画面（1 メイン／2 候補／3 条件付きの候補／4 指名の依頼／5 承認後の声かけ文／6 カード詳細／7 スマホの候補）。

## 外したもの
| 外したもの | 理由 |
|---|---|
| ヘッダーの金額（今回・累計）とモデル名 | 技術広報の判断に使わない。記録は続け、URL に `?debug` を付けたときだけ小さく出す |
| モデル切り替えのお知らせ帯 | 同上（`?debug` の表示に含めた） |
| 「依頼の履歴」「Agentの学び」タブ | 仕様にない。学びはカード詳細の打診履歴で見られる |
| 「自信のある候補」「条件付きの候補」の見出しと破線の枠 | 印「条件付き」1つで区別できる |
| 候補の「自信のある候補」「確認済み」「未発信」「カードなし」「代わりの提案」の印 | 候補カードの印は「条件付き」だけにした |
| 一覧の「候補 N位」の印 | 一覧の行を薄い青にするだけで分かる |
| 声かけ文の「直しました／下書きのまま」の印 | 「下書きに戻す」ボタンの有効・無効で分かる |
| 「承認済み」「記録済み」の印 | 「○○さんで進める」「記録しました：…」の文字で足りる |
| 依頼の種類の青い印（枠だけの依頼 など） | 小さな文字にした |
| 依頼パネル下の使い方の説明文、一覧の「確認済み・新しい順」 | なくても操作に迷わない |
| 「すべて」の絞り込みボタン | 絞り込みをもう一度押せば外れる。件数は見出しに出す |
| 根拠リンクの枠つきボタン | 普通の文字リンクにした |

## 減らしたもの
| 前 | 後 |
|---|---|
| ネタ帳一覧の印 最大6つ（未発信・登壇0回・LT向き・確認済み・新しいテーマ案・候補順位） | 最大2つ：「未発信」か「発信済み」＋「✓ 確認済み」。登壇回数は名前の横に文字で |
| LT向き・ブログ向き、新しいテーマ案の印 | カード詳細へ移した |
| 一覧の1枚＝4行（名前／テーマ2行／印） | 2行（名前・印・日付／テーマ1行） |
| 候補の注意点がオレンジの印で4〜5個 | 薄い文字の1行（省略分はマウスを乗せると全文） |
| 条件付きの理由が枠つきの帯 | オレンジの文字で1行 |
| 指名された本人・代わりの提案の印 | 名前の横に「指名」「指名の代わり」と文字で |
| 「Agentがやったこと」の手順が常に全部表示 | 終わったら「3枚のカードを調べて、3人を選びました（8秒）」の1行。開けば手順と、打診履歴から反映したこと |
| 「Agentのまとめ」の枠、候補ごとの枠、見つからない理由の枠 | 候補を1つの枠にまとめ、細い線で区切る。理由と次に確認すべきことは候補の下の小さな1枠 |
| カード詳細の枠の中の枠（新しいテーマ案、根拠の投稿） | 枠をやめ、細い線で区切る |
| 説明の文（声かけ文・結果の記録・カードを直す） | それぞれ1行に短くした |
| 余白（ページ24px、一覧の行12px） | ページ16px、一覧の行8px |

## 残したもの
- 依頼 → 候補 → この人で進める → 声かけ文（編集・コピーのみ、送信ボタンなし）→ 結果の記録（承諾／辞退と理由）
- カード詳細：カードを直す、新しいテーマ案の採用／却下、根拠の投稿を開く
- ネタ帳の検索と絞り込み（未発信／登壇経験なし／確認済み／事業部）、ブログのネタを出す、ネタ帳を更新
