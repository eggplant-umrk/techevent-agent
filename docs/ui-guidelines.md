# UIガイドライン（ネタ帳Agent）

方向性：LayerXらしい、シンプルな業務ツール。飾らず、情報が速く読めて、迷わず押せること。
参考モック：https://claude.ai/artifact/4ZCHXbjVpiiP4hLCS1XEwg（メイン画面）

## 色
| 用途 | 色 |
|---|---|
| 背景 | #F5F6F8 |
| 面（カード・パネル） | #FFFFFF、枠線 #E3E6EB、角丸 12px |
| 本文 | #1B2330 |
| 補足の文字 | #5B6472（白地でもコントラスト4.5:1以上） |
| アクセント（主ボタン・リンク・選択中） | #1D4FD7、薄い背景 #EEF2FD |
| 未発信・注意 | 文字 #8A4B00、背景 #FFF4E5 |
| 確認済み・完了 | 文字 #157347、背景 #E8F5EE |
| 中立のタグ | 文字 #3A4250、背景 #EEF0F3 |

- アクセントは青の1色だけ。グラデーション、左だけ太い枠線のカード、絵文字は使わない
- 状態は色だけで伝えず、必ず文字のラベルを付ける

## 文字
- Inter ＋ Noto Sans JP
- 見出し 16〜18px／700、本文 14〜15px、補足 12〜13px、行間 1.5〜1.6

## レイアウト
- 上部ヘッダー：アプリ名、タブ（ネタ帳／依頼の履歴／Agentの学び）、今回と累計の金額、「ネタ帳を更新」ボタン
- 本体：左にネタ帳（幅420〜520px）、右に依頼パネル。狭い画面では縦に積む
- 余白は8の倍数。カード内の余白は16〜20px

## 部品
- カード一覧の1行：名前・所属・最新の活動日／テーマ案1行／タグ（未発信・登壇0回・LT向き・確認済み など）
- 依頼パネル：依頼の要約 →「Agentがやったこと」（番号つきの手順と、何で判断したか）→ 候補（0〜5人、登壇経験の印つき）
- 候補カード：順位、名前、テーマ案（太字）、理由1〜2行、根拠のリンク（クリックで元の投稿へ）、注意点のタグ、「この人で進める」（主ボタン）と「カードを見る」
- 声かけ文：編集できるテキストエリア。送信ボタンは置かず「コピー」だけ。「自分の言葉に直して送ってください」と添える
- 結果の記録：承諾／辞退をボタンで選び、辞退なら理由（テーマが合わない／忙しい／予定が重なる／その他）をボタンで選ぶだけ
- 確認済みカードへの新しい提案：「新しいテーマ案（未確認）」の印と「採用」「却下」ボタン
- 候補がいないとき：無理に並べず、「見つからない理由」と「次に確認すべきこと」を表示

## 使いやすさとアクセシビリティ
- 押せるものは本物の button か a。タップ領域は高さ40px以上
- アイコンだけのボタンには aria-label
- 処理中は作業ログが順に増えていき、待ち時間が分かる
- エラーは何が起きて次に何をすればいいかを1文で出す
